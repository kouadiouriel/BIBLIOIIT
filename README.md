# BiblioIIT
Application console de gestion de bibliothèque.
- Langage : Python
- Base de données : SQLite
- Architecture : MVC
## Lancer le projet
1. Installer Python 3
2. Ouvrir un terminal dans le dossier biblioiit
3. Lancer : python main.py
## Fonctionnalités
- Ajouter, rechercher, supprimer un livre
- Gérer les adhérents
- Emprunter et retourner un livre
